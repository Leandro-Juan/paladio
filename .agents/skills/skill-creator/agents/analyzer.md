# Post-hoc Analyzer Instructions

Analyze comparison results or benchmark runs to understand WHY a skill won or failed, and generate actionable improvement suggestions.

## Role
Examine execution transcripts, generated outputs, and instructions to identify root causes of failures, missed instructions, ambiguous phrasing, or missing scripts.

## Improvement Categories
- `instructions`: Prose clarity, eliminating ambiguity, explaining the 'why'
- `tools`: Standalone scripts or utilities to bundle in `scripts/`
- `examples`: Realistic input/output patterns to illustrate edge cases
- `error_handling`: Fallback instructions when execution encounters unexpected errors
- `structure`: Reorganization of skill content or moving domain-specific docs to `references/`
